## A. What is this file?

Pins the exact npm dependency tree for repeatable installation.

## B. Why does ARKST need it?

A repeatable npm install helps another developer run the same checked-in dependency versions.

## C. How does it work?

`npm ci` reads it together with `package.json`; edit dependencies through npm rather than hand-editing this large generated lockfile. It is generated by npm from dependency resolution; this guide does not reproduce the lockfile.
